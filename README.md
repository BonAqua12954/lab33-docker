# Лабораторная №33 — Контейнеризация и оркестрация

Учебный проект по дисциплине: упаковка HTTP-сервиса в Docker-контейнер,
запуск многоконтейнерного стека через Docker Compose и развёртывание
в Docker Swarm с репликами и rolling update.

## Что это

Небольшой HTTP-сервис на Flask, который использует Redis как хранилище счётчика.
Демонстрирует:
- Multi-stage сборку Docker-образа.
- Конфигурацию через переменные окружения.
- Связку приложения и Redis через именованную сеть.
- Сохранение данных Redis через именованный volume.
- Оркестрацию в Docker Swarm: 3 реплики приложения и rolling update.

## Эндпоинты

| Метод | Путь      | Описание                                         |
|-------|-----------|--------------------------------------------------|
| GET   | `/`       | Возвращает `Hello, Docker!`                      |
| GET   | `/health` | Проверяет живость сервиса и соединение с Redis   |
| GET   | `/count`  | Инкрементирует счётчик в Redis и возвращает его  |

## Стек

- Python 3.11
- Flask 3.0.3
- Redis 5.0.7 (клиент), Redis 7 (сервер)
- Docker, Docker Compose, Docker Swarm

## Переменные окружения

| Переменная   | Значение по умолчанию | Назначение                     |
|--------------|-----------------------|--------------------------------|
| `PORT`       | `5000`                | Порт, который слушает Flask    |
| `REDIS_HOST` | `redis`               | Хост Redis в сети Docker       |
| `REDIS_PORT` | `6379`                | Порт Redis                     |
